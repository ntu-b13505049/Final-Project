# 管理者借還紀錄與介面調整

本次調整內容：

1. 管理者端新增「查看選取使用者借還紀錄」。
   - 位置：管理者介面 → 使用者管理 → 選取使用者 → 查看選取使用者借還紀錄。
   - 也可在借還紀錄頁選取一筆紀錄後，查看該借閱者完整借還紀錄。

2. 登入、登出時不再改變視窗大小。
   - Login、學生端、管理者端統一使用 1400 x 860 視窗大小。

3. 搜尋改為自動搜尋。
   - 使用者端書籍查詢：輸入題名、作者、主題、出版者、ISBN 後自動查詢。
   - 管理者端借還紀錄、使用者、書籍、書評、預約、等級申請：輸入或切換篩選條件後自動更新。

4. 登入支援 Enter。
   - 學生登入與管理者登入可在密碼欄按 Enter 登入。

5. ISBN 搜尋加強。
   - 支援貼上完整 ISBN 清單。
   - 支援含逗號、空格、冒號、ISBN 字樣、連字號的 ISBN 文字。

6. 逾期資料醒目標示。
   - 使用者端首頁提醒、目前借閱、借還歷史。
   - 管理者端借還紀錄、單一使用者借還紀錄、單本書借還紀錄。

7. 字體放大與按鈕位置調整。
   - 全域字體調大。
   - 表格列高調高。
   - 管理者書籍新增 / 修改 / 上下架按鈕移到書籍資料表單下方，避免離資料欄位太遠。
